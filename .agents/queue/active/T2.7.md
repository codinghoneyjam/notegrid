## Notes

- SCOPE was extended to `packages/app/{package,tsconfig}.json`, `packages/persistence/{package,tsconfig}.json`,
  `e2e/**` and `.gitignore`. A package with no `test`/`check` script and no
  `tsconfig.json` cannot be tested or type checked, T04.AC6 needs the e2e
  harness to exist at all, and the harness produces build output that has to be
  ignored. Recorded in `docs/tasks/DECISIONS.md` (2026-10-09).
- Playwright is installed in `e2e/` as its own package rather than a workspace
  member: the harness bundles TypeScript sources with esbuild and serves the
  built wasm, and pulling a browser-downloading tool into the workspace install
  would make `pnpm install` on CI far heavier than the rest of the tree.
- The pipeline order is validate, then migrate, then canonical -- the reverse of
  the T04 DESIGN line. See the note on `ProjectStore.openBytes`.
- `validate_structure` returns early on the first structural failure, so
  semantic errors (`E_LANE_MISSING`) are hidden behind structural ones
  (`E_RANGE`). Two tests pin that rather than leaving it as a surprise.
- A file written and reopened comes back with notes in canonical
  (start, lane, pitch) order, which is not necessarily the order the editor
  holds them in. `addNote` appends, so an unsaved project and a reloaded one can
  differ in array order while holding the same notes. Recorded in
  `docs/tasks/DECISIONS.md`.
- `T04.AC4` (bank cache) is not in this task's DONE WHEN; T3.4 owns it.
