## Notes

- SCOPE was extended beyond the roadmap's `packages/playback/src/sync/**`, because a
  package with no `test`/`check` script and no `tsconfig.json` cannot be tested, and
  because `packages/abi`'s `exports` pointed at `./src/index.js` while the file is
  `./src/index.ts`, so no package could import `@ng/abi` at runtime. Recorded in
  `docs/tasks/DECISIONS.md` (2026-10-09).
- `src/sync/index.ts` and every other specifier in this slice end in `.ts`, not `.js`.
  Node's type stripping does not remap `.js` onto a `.ts` file, and this barrel is the
  package's runtime entry point. The `document` and `editing` packages use `.js`
  because their barrels are never loaded at runtime.
- `tsconfig.json` sets `allowImportingTsExtensions`, which is why the `.ts` specifiers
  type check.
- The policy takes an injected `Clock`; every timing constant (50 ms debounce, 250 ms
  audition hold, 2 s watchdog) is exercised with a hand-driven clock, so the tests
  never sleep.
- Two contract gaps were found and are recorded in `docs/tasks/BLOCKERS.md` instead of
  being worked around: `ng_engine_set_mix` and `ng_engine_audition` return
  `E_NOT_IMPLEMENTED`, and the document loop is in ticks while `ng_engine_set_loop`
  takes samples with no conversion entry point in the ABI. The playhead tests
  therefore run with `loop: null`, and a dedicated test pins the unit boundary.
