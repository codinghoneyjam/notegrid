# docs/tasks

Task progress for NoteGrid. Everything here is either generated from the spec or hand-written
against it; nothing in this folder is a second source of truth.

## Where state actually lives

`STATE` inside each TASK block in `spec/dsl/03_roadmap.dsl`. The vocabulary is TASK_FLOW from
`00_dsl.dsl` — `ORIENT`, `TEST_FIRST`, `IMPLEMENT`, `VERIFY`, `DONE`, `BLOCKED` — plus
`NOT_STARTED` for a task nobody has entered. A task with no `STATE` line counts as `NOT_STARTED`;
writing it out on all 45 tasks would be noise nobody keeps current.

## Files

| file | what it is | who writes it |
|---|---|---|
| `board.md` | the progress table, grouped by phase | generated by `scripts/check_task_state.py` |
| `BLOCKERS.md` | what is stopped and why, with the decision needed | hand-written, on the task that is blocked |
| `DECISIONS.md` | decisions taken that the spec does not yet record | hand-written, then folded into the spec |

## The check

```
python scripts/check_task_state.py            # regenerate board.md
python scripts/check_task_state.py --check    # what CI runs: board.md must match the spec
```

Three things fail it:

1. a `STATE` that is not a TASK_FLOW state
2. `STATE DONE` on a task whose `SCOPE` names a crate or package that does not exist in the
   workspace, or whose `DONE WHEN` is empty
3. a task `DONE` while an earlier task in the same phase is not finished and not `BLOCKED`

Rule 2 exists because this repo has been wrong about its own progress twice, both times
invisibly:

- `00_dsl.dsl` declared g01 as `fmt ; clippy ; hotpath lints deny { unwrap_used, expect_used,
  indexing_slicing, panic }`. The third clause had no implementation anywhere — no `[lints]`, no
  `clippy.toml`, no marker — so g01 passed while protecting nothing.
- `spec/dsl/TASK_PLAN_P1.md` recorded T1.1 through T1.8 as `DONE` when none of their crates
  (`ng-timeline`, `ng-dsp`, `ng-synth`, `ng-render`, `ng-export`) existed.

A progress file nobody can falsify is worse than no progress file, so `DONE` is a claim about the
workspace and gets checked against it.
